# Customer Churn Prediction Platform using Databricks MCP


An end-to-end production-style Customer Churn Prediction Platform built using Databricks, Apache Spark, MLflow, Unity Catalog, Databricks Asset Bundles, and Claude Code via the Databricks MCP Server.

The entire platform—from synthetic data generation to ML deployment—was built primarily through the CLI using an AI agent.
